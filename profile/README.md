## Start here

### [SIAM.AI GPU Watch](https://github.com/siamaicorp/GPUWatch)

Check remote NVIDIA GPU servers from your Mac's menu bar. See which hosts are reachable, how many GPUs respond, and each card's temperature, utilization, and VRAM usage.

- Connects over SSH using your existing configuration and keys.
- Compares GPU UUIDs against a baseline to identify missing cards.
- Keeps connection failures separate from GPU status.
- Requires macOS 14+ and servers with SSH and `nvidia-smi`.

[View source and setup instructions →](https://github.com/siamaicorp/GPUWatch#readme)
