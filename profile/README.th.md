เราคือ SIAM.AI บริษัทด้านคลาวด์และโครงสร้างพื้นฐาน AI ในประเทศไทย ทำงานตั้งแต่ระบบ GPU สำหรับประมวลผล การฝึกและให้บริการโมเดล ไปจนถึงระบบที่รองรับการทำงานเหล่านี้

GitHub แห่งนี้รวบรวมโครงการที่ทีมเปิดเผยต่อสาธารณะ เริ่มลองใช้จากเครื่องมือด้านล่าง อ่านโค้ด หรือส่งข้อเสนอแนะจากการใช้งานของคุณได้

## เริ่มจากโครงการนี้

### [SIAM.AI GPU Watch](https://github.com/siamaicorp/GPUWatch)

ดูสถานะ NVIDIA GPU บนเซิร์ฟเวอร์จาก Menu Bar ของ Mac เช็กว่าเครื่องไหนยังติดต่อได้ GPU ตอบกลับกี่ใบ พร้อมดูอุณหภูมิ การใช้งาน GPU และ VRAM ของแต่ละใบ

- เชื่อมต่อผ่าน SSH ด้วย config และ key ที่ใช้อยู่แล้ว
- เทียบ UUID กับ baseline เพื่อระบุการ์ดที่หายจากผลตรวจ
- แยกปัญหาการเชื่อมต่อออกจากสถานะ GPU
- ใช้กับ macOS 14 ขึ้นไป และเซิร์ฟเวอร์ที่มี SSH กับ `nvidia-smi`

[ดูซอร์สโค้ดและวิธีติดตั้ง →](https://github.com/siamaicorp/GPUWatch#readme)
